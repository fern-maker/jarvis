# Jarvis

A personal AI assistant that facilitates everyday life. Jarvis is always listening for your voice, and remembers context.

Built for the Nebius × NVIDIA AI Hackathon (Personal AI Track).

## Setup

```bash
pip install -r requirements.txt
python -m src.main
```

## Training Data

Training data is in `training/data/raw`
